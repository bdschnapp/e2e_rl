# Ch6: Simulation Environment — Summary

**Environment**: Custom 2D Gymnasium + Pygame (NOT Gazebo). Discrete-time tractor-trailer dynamics re-evaluated each step. Pygame renders top-down view for BEV image capture.

**Tasks**:
1. `LineFollowing` (`Environments/LineFollowing.py`): Random cubic-spline lane, reward for keeping tractor+trailer in lane
2. `ObstacleAvoidance` (`Environments/ObstacleAvoidance.py`): Lane + static obstacles; collision terminates episode

**Vehicle params** (same as ME780/ECE682):
`m=1500kg, Iz=3000, Cf=Cr=80000 N/rad, lf=1.2m, lr=1.6m, Cd=0.208, A=2.4m², dt=0.1s`

**Action space**: `[δ̇, v]` ∈ [-15°/s, 15°/s] × [0, 2 m/s] — steering RATE (not angle), consistent with ECE682 finding that angle can't be set instantaneously.

**Episode termination**: collision (Pygame mask), jackknife (|γ| > 90°), or path completion.

**Baselines compared**:
- PID (ME780: 0.784m CTE)
- LQR (ECE682)
- MPC via OSQP (`controllers/mpc.py`)
- ME780 DDPG (0.505m CTE) — single vehicle reference

**NOT implemented**: Gazebo, ROS2, Agilex hardware, URDF models, LIDAR, noisy sensor simulation, sim-to-real transfer — all future work.
