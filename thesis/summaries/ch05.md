# Ch5: RL Framework — Summary

**Algorithm: TD3** (Twin Delayed Deep Deterministic Policy Gradient)
- Extends ME780 DDPG with: twin critics (reduces overestimation bias), delayed policy updates, target policy smoothing
- Actor: μ(s|θ) → deterministic action; Critics: Q1, Q2(s,a|θ) → value estimate
- Target: y = r + γ_d · min(Q1, Q2)(s', μ(s') + clip(N(0,σ), -c, c))
- Implemented via Stable Baselines3

**Reward function** (in `equations/reward_function.tex`):
- Multiplicative structure (from ME780 finding): R = f(e_y) · f(e_ψ) · f(γ) · f(collision)
- Multiplicative forces agent to minimise ALL components; additive allows exploiting partial credit
- Exponential decay terms: e^(-|e_y|), e^(-|e_ψ|), e^(-|γ|)
- Collision penalty: terminal negative reward

**Decision Transformer** (described but not primary):
- Offline RL; trained on recorded TD3 trajectories
- From ME780: needs diverse training data (step discontinuities, high-error states) to avoid oscillation
- Relevant for tractor-trailer because long-range dependencies (jackknife builds up slowly)

**Hyperparameter tuning**: Grid search over learning rates, buffer size, noise scale. Tables in `appendices/appendix_hyperparameters.tex`.

**Key constraint**: Reward must penalise |γ| — path accuracy alone is insufficient for articulated vehicle safety.

**Failure Replay Curriculum** (`sec:failure_replay`):
- On episode failure (jackknife/collision/OOB), replay the same seed → same path + spawn
- On success or timeout: fresh random reset as normal
- Max 5 consecutive retries to avoid getting stuck on pathological layouts
- Orthogonal to reward/obs ablations; controlled by `--retry_on_failure` flag
- Most beneficial for reverse tasks (high failure rate, non-uniform layout difficulty)
- Implemented in `Environments/wrappers.py` as `RetryOnFailureWrapper`
