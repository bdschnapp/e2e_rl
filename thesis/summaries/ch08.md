# Ch8: Conclusion — Summary

**Contributions demonstrated**:
1. Combined dynamic tractor + kinematic trailer model in Gymnasium/Pygame
2. BEV image observation space (84×84 grayscale from Pygame render)
3. TD3 agent for lane-following and obstacle avoidance
4. Comparison with PID, MPC, ME780 DDPG

**Limitations**:
- Simulation only (2D Pygame); no 3D physics, no hardware testing
- 2D dynamics don't capture load transfer, tire saturation, hitch compliance
- Fixed payload (hitch dynamics vary with trailer mass)
- Static obstacles only

**Future work** (in order of priority as written):
1. Higher-fidelity simulation (Gazebo, URDF model)
2. Hardware deployment (Agilex platform, sim-to-real)
3. Decision Transformer for tractor-trailer
4. Multi-trailer systems (B-train)
5. Online adaptation for payload changes
6. Control Barrier Functions as safety overlay
7. Dynamic obstacles
