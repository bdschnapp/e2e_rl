# Ch4: Perception & Observation Space — Summary

**BEV image**: 84×84 grayscale, rendered by Pygame camera anchored to tractor rear axle. Configurable zoom/offset in `e2erl_utils/config.py`. Encodes lane markings, obstacles, vehicle footprints.

**Observation dict**:
- `vector`: [δ, γ, e_y, e_ψ, and their derivatives] — precise numerical state
- `image`: 84×84 BEV — spatial context (lane geometry, obstacles)

**CNN encoder** (`Models/CNNFeatureExtractor.py`): Wraps ImageEncoder as SB3 custom feature extractor. Processes BEV image → feature vector. Concatenated with vector obs before TD3 actor/critic. Trained end-to-end with TD3.

**UNet** (`Models/UNet.py`, `Models/UNetFeatureExtractor.py`): Alternative encoder using UNet architecture.

**Autoencoder** (`Models/AutoEncoder.py`): Pre-trained on simulation rollout images. Compresses BEV → latent z → reconstructed BEV. Agent operates on z, reducing policy network parameters.

**Collision detection**: Pygame mask overlap (pixel-precise). Terminates episode on contact.

**NOT implemented**: LIDAR, ROS2 point clouds, Basler cameras, sensor fusion, WATonoBus sensors — all future work.
