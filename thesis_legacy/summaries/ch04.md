# Ch4 Summary

- Title: observation/representation design, reward formulation, and policy training
- Action space: continuous steering-rate + a stop/go signal (thresholded [-1,1]); speed FIXED at ±5 m/s (not commanded). Stop-capable across all learning-based tasks; discrete algos use a joint steer×{go,stop} set. Stop = failure (penalized) in obstacle-free/phase-1; rewarded only on hard obstacle layouts
- Core system: TD3 on 8-D engineered state; reward variants (dense, tractor-focus, multiplicative, guided). Guided = interpolation from pure-pursuit imitation (-5*Δδ²) to the MULTIPLICATIVE reward via schedule α_k (α=1 is a pure PP clone)
- Obstacle reward: geometric difficulty d; difficulty-gated stop reward = s(d)*60 - (1-s(d))*60 + progress*20 (matches code); slow-on-hard bonus; failure uses the standard -500 terminal (no separate R_fail); branching hidden-path reward (two hidden corridors)
- Observations: state, lidar (N beams), BEV (binary occupancy OR graded signed-distance + optional CoordConv)
- Encoders: compact CNN (LayerNorm + separate actor/critic); scaled-CNN diagnostic; autoencoder/UNet pretraining
- Training high-dim policies: off-policy actor-vs-cold-critic instability HYPOTHESIS (Ch5 confirms). THREE decoupling routes as a progression: (A) reconstruction pretraining (partial), (B) behaviour-cloning warm-start (works, fragile unfreeze, can't prove CNN uses image), (C) GEOMETRY DISTILLATION = headline: supervised predict geometry from BEV alone (learning-by-cheating), freeze encoder, TD3 from scratch on [true δ,γ proprio + predicted exteroceptive errors/curvature]; removes both failure modes, proves image is a sufficient statistic for geometry
- Safe adaptation: freeze-actor / TD3+BC anchor / residual; α_k schedule = imitation→improvement transition (same as guided reward)
- Failure-replay curriculum; obstacle Stage A→B curriculum; off-policy LR 1e-3, 32 envs; algorithm comparison uses per-algorithm settings
- Evaluation methodology: difficulty-stratified, Wilson CIs, crash-conditional-on-attempt, PP drivability oracle, EV break-even at P_clear=83.3% -> d* (numbers in Ch5)
- Scalable simulation: batched NumPy/CuPy GPU env, parity, throughput
- Placement rule: design/why here; numbers/results in Ch5. Geometry-encoder R² and parity curves are Ch5.
- New citations: fujimoto2019bcq, fujimoto2021td3bc, yarats2021sacae, liu2018coordconv, chen2020cheating
